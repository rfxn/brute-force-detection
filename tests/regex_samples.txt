# BFD Regex Pattern Samples — data-driven test corpus
#
# Format:
#   # RULE: <rule_name>       — matches files/rules/<name>
#   # PATTERN: <pattern>      — exact extract_hosts() pattern to test
#   # EXPECT: <ip|NONE>       — expected extracted IP, or NONE for negative tests
#   # IGNOREREGEX: <pattern>  — set IGNOREREGEX for this sample (optional)
#   # NOTE: <text>            — optional explanation
#   <log line>                — the sample log line (next non-comment non-blank line)
#
# All IPs use RFC 5737 documentation ranges:
#   IPv4: 192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24
#   IPv6: 2001:db8::/32
#
# Adapted from CSF regex.txt, fail2ban test fixtures, and BFD test suite.
